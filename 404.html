❓ FAQ

Honest Answers

Is it really free forever? What's the catch?

Yes — this website itself is a static page hosted free on GitHub Pages, and the bot engine runs in your browser using Telegram's free Bot API. There is no server bill for anyone, so there's nothing to charge you for. No login, no card, no trials, no limits on bots or rules.

Does my bot run when I close this tab?

The in-browser runner needs the tab open (it literally runs on your device — that's why it's free and private). For closed-tab 24/7 operation, use the 24/7 Deploy Export: we generate a complete Python/Node project with your rules baked in, ready for free hosts like Render, Railway, Koyeb or Replit.

Is my bot token safe?

Tokens are saved only in your browser's localStorage and are sent only to api.telegram.org. This site has no backend and no analytics — view the page source and verify. Still, treat tokens like passwords: if one leaks, revoke it instantly via @BotFather → /revoke.

How many bots / messages can I handle?

Unlimited bots and rules on our side. Telegram's own Bot API limits apply (~30 messages/sec per bot), which is far more than most bots ever need.

I cleared my browser data and lost my bots!

Without a login there's no cloud copy — that's the privacy trade-off. Use Backup → Export regularly and keep the .json file safe (it contains tokens). You can also re-add a bot anytime with its token from @BotFather (/mybots).

Can I use Python instead of JavaScript?

In-browser: use No-Code Rules or the JS Code Lab. For Python, use the Deploy Export — it generates a full python-telegram-bot project with your rules converted automatically.

Why does a running bot say "Conflict: terminated by other getUpdates"?

That token is being polled somewhere else (another tab, host, or script) or has a webhook set. Stop the other instance, or delete the webhook in the Tools section, then start again here.
